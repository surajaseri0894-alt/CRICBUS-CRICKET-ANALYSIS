# CricBuz IPL Dashboard

## Overview

The CricBuz IPL Dashboard is an interactive Excel-based data analytics project that provides comprehensive insights into IPL player and season performances. The dashboard visualizes batting and bowling statistics, season-wise runs, and key performance indicators through dynamic and user-friendly visuals.

---

## Objectives

- Analyze IPL batting and bowling performances.
- Track season-wise total runs.
- Compare player statistics using dynamic player cards.
- Present cricket analytics through an interactive dashboard.

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts

- Excel Formulas
- Data Cleaning and Transformation
